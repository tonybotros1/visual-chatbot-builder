## Bugs found and fixed

1. **Questions inside a component (subflow) could not be answered in the published chat.** Provider validation looked the node up in the bot's flow only. Now resolved from the active runtime frame (`services/providers.py`), which also makes uploads, payments, appointments and OTP work inside components.
2. **Validator rejected conditions on variables written by rule sets, decision tables or components** (`missing_condition_variable`). Output mappings now count as defined variables.
3. **Logic evaluate returned 500** for facts of the wrong type. Now 422 with the message.
4. **Custom-domain verification returned 500** for an unresolvable hostname. Now 422.
5. **Audience targeting rules were stored unvalidated**, so a mis-shaped rule silently matched everyone. Rules are now typed (`TargetingRules`) and bad shapes are rejected with 422.
6. **Collaborators with too low a role got 404** on forbidden actions; now 403 with the required role in the message.
7. **Visitor chat layout broke when the progress bar was enabled**: the 340px transcript row went to the 4px bar, leaving most of the card blank. Fixed with a four-row grid when the bar is present.

Also fixed earlier in the same day and re-verified here: canvas drag freeze on large flows, canvas fitting on load, in-chat language switch with RTL, localized runtime strings, link pill colours, worker start race, QA expectation schema, stable and editable slugs.
